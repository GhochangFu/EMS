# E7.1i Tenant-Scoped Audit Read Index Implementation Plan

> For agentic workers: use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a tenant-leading composite index so organization-scoped audit-log list and export reads seek directly into the tenant's newest records while preserving the existing global chronological index.

**Architecture:** One forward-only Drizzle SQL migration creates a normal B-tree index on bms.audit_log (organization_id, created_at DESC, id DESC). The existing audit_log_created_idx remains for unscoped fleet-admin reads. No API, auth, response-contract, or frontend changes are required because both scoped consumers already share AuditService.selectRows.

**Tech Stack:** PostgreSQL 16/TimescaleDB, Drizzle SQL migrations, Vitest static repository invariants, pnpm, Docker Compose.

**Spec:** docs/BACKLOG.md E7.1i and docs/adr/0046-audit-log-reader-organization-scope.md.

## Constraints and invariants

- Work only in isolated worktree feat/E7.1i-audit-log-index; do not switch or modify the shared checkout.
- Use a new migration; never edit an applied migration. Append the matching entry to packages/db/drizzle/meta/_journal.json.
- Use schema-qualified names, IF NOT EXISTS, SET ROLE bms_owner, and RESET ROLE. Do not use CREATE INDEX CONCURRENTLY because Drizzle runs migrations in a transaction.
- Keep audit_log_created_idx; it supports global-admin reads with no organization predicate.
- Add a top-level static test to the explicit typecheck:tests list in the root package.json, matching existing migration-invariant tests.
- Follow TDD: add and run the failing invariant before creating the migration; then implement and rerun it.
- Do not change API behavior, auth, contracts, dependencies, seed data, or UI.

## Task 2: Implement the forward-only migration

Files: create packages/db/drizzle/0049_audit_log_organization_created_index.sql; append the exact idx 49 entry above to packages/db/drizzle/meta/_journal.json.

Migration SQL:
-- E7.1i: make tenant-scoped audit-log reads seekable.
SET ROLE bms_owner;

CREATE INDEX IF NOT EXISTS audit_log_organization_created_idx
  ON bms.audit_log (organization_id, created_at DESC, id DESC);

RESET ROLE;
