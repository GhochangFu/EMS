## 0. Goal, and what is out

**Goal.** Three new global symbol libraries in the `0090` shape — `qet` (QElectroTech elements, CC BY 3.0, pinned `qelectrotech/qelectrotech-elements@3b12bc579b99932e3fe307ea1e44b8c1c6d1d5c9`), `wmpid` (Wikimedia Commons `Category:P&ID symbols`, public domain and CC0 files only, each pinned by `sha1` + `timestamp`), `drawio` (draw.io `pid` and `electrical` stencil sets at `jgraph/drawio@48b181339578e11da7052ebf5b1fba8499418b77`, v29.3.2, CC BY 4.0 per the owner's ruling). Each is: a row in `bms.mimic_symbol_libraries` and one row per symbol in `bms.mimic_symbols` (hand-written migration `0092`), a curation list, and generated modules from `scripts/mimic-symbols/generate.mjs` (shared keys/labels/groups, web shapes + licence notice, and — new — per-file credits the attributions page shows). Fetching happens at generation time on the implementer's machine, never in CI. The PR states the counts per library and the measured bundle growth.

**Out.** Organization libraries, the switch, SVG upload, the API module and the read-side shape check on API responses (slice 3, decisions 1–4, 6, 7); the attributions page itself and the carried fixes (slice 1, decisions 5, 8, 10) — slice 2 only adds per-file credits to the page slice 1 built; any change to `0088`–`0091`, presets, seeds, `MimicScene` layout code, Tailwind class conversion (F3.71), `AGENTS.md`. ## 3. Curation (what U1–U3 check in)

- **qet (≈120, R5).** From `30_hydraulic` (tanks, pumps, valves, cylinders, exchangers, filters → `water`, `mechanical`), `60_energy/11_water` (boilers, radiators, expansion vessels, circulation pumps, mixing valves, meters → `water`, `hvac`, `facility`), `60_energy/21_refrigeration` (compressors, condensers, evaporators, expansion valves, fans → `hvac`), `60_energy/31_solar_thermal` (collectors, storage → `environment`, `facility`), `50_pneumatic` (compressors, air treatment, actuators, sensors → `mechanical`, `environment`). Pick from `qet-paths.txt`; English slugs written by the curator from `<name lang="en">`. Elements whose meaning is a text label or an arrow end are skipped.
- **wmpid (target ≈150 of 424, R5).** `wmpid-curate.mjs` lists every `image/svg+xml` file with `Public domain` or `CC0` and no `Sheet`/`Symbols` composite title, with `sha1`, `timestamp`, `url`, author and templates. The curator sorts plant-relevant titles into groups: vessels/tanks/filters/pumps/valves → `water`/`general`; heat exchangers, compressors, fans, driers → `hvac`/`mechanical`; instruments, sensors → `environment`; electrical → `electrical`; the chemical unit operations (ChemSim's reactors, columns, crushers) mostly stay out. A file the converter refuses (`text`, `use`, gradient, `image`) is removed from the list, not patched.
- **drawio (≈120, R5).** `pid`: pumps (all three sets, de-duplicated by drawing), valves, vessels (a subset), heat exchangers, filters, compressors, flow sensors, instruments, agitators/mixers, piping/fittings (a few); `electrical`: `electro-mechanical`, `transmission`, `instruments`, `miscellaneous` (motors, generators, transformers, switches). Every vendor set is excluded (ADR decision 9). Slugs from the stencil name; a collision across sets prefixes the set (`din-`, `iso-`).

## 10. Rulings for the owner (the ADR is silent; defaults recommended)

- **R1 Coordinates.** Every converted symbol is fitted into the renderer's 24×24 box (uniform scale, centred), baked into the numbers with 2 decimals — so strokes stay 1.5 like the other libraries and the bundle stays small. A Commons shape whose composed matrix has rotation or skew keeps its source numbers and carries `transform="matrix(…)"` (the ADR's literal path). Alternative: `transform` on every Commons shape — thinner strokes (≈0.34×) and larger modules.
- **R2 Transform grammar.** `matrix|translate|scale|rotate|skewX|skewY` with numbers only (`-?(\d+\.?\d*|\.\d+)(e-?\d+)?`), numbers separated by one comma or one space, functions by one space, ≤ 256 chars, no leading/trailing space. The generator emits only a single `matrix(a,b,c,d,e,f)`.
- **R3 Grammar location.** `packages/shared/src/contracts/mimic-shapes.ts` as Zod (`mimicShapeSchema`), including the `d`/`points`/number grammars decision 6 needs, so slice 3 imports it; web `shapes.ts` re-exports.
- **R4 Curation format.** Object entries per group for the three new libraries (D5); the existing three keep string lists (0090 data is never regenerated). Labels = `labelOf(name)`; QET slugs are English, chosen by the curator.
- **R5 Counts.** `qet` ≈ 120, `wmpid` target ≈ 150 of 424 (single-symbol PD/CC0 SVGs, plant-relevant by title, passing the converter), `drawio` ≈ 120; each ≥ 100 (the gate's positive control); exact numbers in the PR.
- **R6 `version` values.** `qet` `0.100`, `wmpid` `2026-09-29` (walk date), `drawio` `29.3.2`; full commit pins go in the notices and per-file credits (`varchar(32)` cannot hold a 40-char sha).
- **R7 Labels and order.** `QElectroTech`, `Wikimedia Commons P&ID`, `draw.io`; `sort_order` 50/60/70; `style` `stroke`; sources `qelectrotech/qelectrotech-elements`, `Wikimedia Commons Category:P&ID symbols`, `jgraph/drawio stencils (pid, electrical)`; attribution URLs `https://qelectrotech.org/wiki/doc/elements_license`, `https://commons.wikimedia.org/wiki/Category:P%26ID_symbols`, `https://github.com/jgraph/drawio/tree/48b181339578e11da7052ebf5b1fba8499418b77/src/main/webapp/stencils`.

- **R9 Fetching.** `scripts/mimic-symbols/fetch-sources.mjs {qet|drawio|wmpid} --out <dir>` reads the curation files, hits only `raw.githubusercontent.com` at the pinned commits and `commons.wikimedia.org` / `upload.wikimedia.org`, pauses 1.5 s (Commons) / 250 ms (GitHub), sets a `User-Agent`, verifies `sha1` (Commons) and refuses an HTML body.
