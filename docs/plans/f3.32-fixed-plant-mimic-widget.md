# F3.32 v1 — the fixed plant mimic widget (ADR 0079) — step-3 plan

Plan by `plan-architect` (Fable), 2026-09-28, against `origin/main` `2833a102`
plus the ADR branch; ADR 0079 merged as `5b608494` (#623). Branch
`feat/F3.32-mimic-widget`. Merge cutoff: end of day 2026-09-30.

## 0. Goal, and what is out

**Goal.** One new widget type, `mimic`, in the ADR 0047 builder. Its config is
`{ source: "preset", preset: "water_train" }`. On a dashboard scoped to one
asset group it draws a fixed SVG train — intake → WTP → RO → softener →
storage, cooling tower off storage, STP → ETP → discharge — where each node
resolves **at read time** to the group member carrying the node's
`bms.asset_roles` code, shows that member's top three points by
`point_keys.headline_rank`, a status colour (live / alarm / stale / not
assigned, dimmed), live values over `/ws/telemetry`, and a `+N` badge when the
role matches more than one member. The API refuses the widget on a location-,
asset- or unscoped dashboard (400) and refuses to instantiate a template
holding one without an `assetGroupId` (400). Seven role codes and a demo
group + dashboard on the seeded `WTR-` plant land with it.

**Out (ADR 0079 decision 8).** A drawing surface, user presets, a second
preset, network mimics, KPI overlays beyond the node values, the SMOC pages, a
type picker in the section-template editor (Q2), and any `AGENTS.md` §6 change.

## 2. Decisions

- **D1** One read: `GET /api/v1/dashboards/:id/mimic-nodes`, every mimic widget
  on the dashboard with resolved nodes and top-three points with their latest
  sample. Declared before `:slug`.
- **D2** The web reuses F3.68's live machinery through a synthetic
  `GeneratedSiteViewDto`. Refetch every 30 s.
- **D3** Preset definitions in `packages/shared` (code); node coordinates in web.
- **D4** A node's asset reuses `generatedSiteAssetSchema`. Plain `z.object`; no
  `.merge()/.extend()/.pick()/.readonly()`.
- **D5** Status precedence: `unassigned` → `alarm` → `live`/`stale`/`none`.
- **D6** A member outside the caller's readable asset set reads "Not assigned".
- **D7** Two migrations: `0086` widens the CHECK, `0087` inserts the seven codes.
- **D8** `mimicConfigSchema` does not spread `commonConfigFields`; generic
  `unit/decimals` reads guard with `"unit" in widget.config`; the inspector hides
  Unit/Decimals for a mimic.
- **D9** The template editor gains no type picker.

## 8. Review ruling (F3.32 review-fix, 2026-09-28)

U3's `update()` guard removed after review: a PATCH that moves the scope then a
PUT that deletes the mimic got a false 400 from a guard checking a
pre-transaction snapshot; a stored mimic on a group-less dashboard already
reads as 8 unassigned nodes (U2), and ADR 0079 decision 4 asks only that a
mimic is not *placed* there — the `putWidgets` guard alone holds that. `hasMimicWidget`
was removed with it (no other caller).
