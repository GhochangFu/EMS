## 0. Goal, and what is out

**Goal.** A unit's symbol comes from one of four preloaded libraries — `core` (the 29 existing glyphs), `tabler` (MIT, stroke), `lucide` (ISC, stroke), `mdi` (Apache 2.0, fill) — about 430 keys in all. Keys are `<library>:<name>` except the bare core keys, so every stored layout, preset and widget keeps its value (decision 2). Path data is vendored as generated TypeScript in `apps/web`, drawn as React elements inside the existing `MimicGlyph` wrapper (decision 5); keys, labels and groups live in `packages/shared` and in two global lookup tables that migration `0090` creates and fills (decisions 1, 7); `mimic_layout_nodes.symbol` widens to `varchar(64)` and a foreign key to `bms.mimic_symbols(key)` replaces `mimic_layout_nodes_symbol_check` (decision 3). A layout chooses its libraries in `mimic_layouts.symbol_libraries` (default `{core}`); the editor offers them as check boxes, the palette shows one tab per chosen library with the eight groups and a search box, the inspector's symbol select lists the chosen libraries grouped, and a save refuses a unit whose library the layout did not choose (decisions 8, 9). Colour stays with the role token: a `fill` library draws with the matching fill class of the same role (decision 6). Existing layouts read as `{core}` and draw pixel-identically.

**Out (ADR 0084 decision 10 → `F3.32f`).** Organization-owned libraries, an administrator enable switch, SVG upload and its sanitizer, an attributions page, QElectroTech / Wikimedia / draw.io sources. Also out: any change to `MimicScene`, the resolver (`mimic-nodes.service.ts`), presets, seeds, `AGENTS.md` §6, a `/vocabularies` field for libraries (the shared registry is the source until `F3.32f`), refusing a save that names an *inactive* symbol (the FK admits it; nothing makes a symbol inactive in this release), and any new manifest dependency.
