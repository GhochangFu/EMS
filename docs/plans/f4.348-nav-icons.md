## PR 1 — the icons (web only), with the row's close-out

Files: `apps/web/src/layouts/shells/{navigation-model.ts,nav-icon.tsx,sidebar-shell.tsx,rail-shell.tsx}`,
`apps/web/src/lib/design.ts` (`DESIGN_TOKENS`), `apps/web/src/index.css` (the
four tokens in all ten design blocks; one `.nav-icon` rule), the shell specs,
the sidebar markup fixture (re-captured: the icons are new markup, by this
amendment), `docs/BACKLOG.md`, ADR 0118 *As built*.

Tests first:

- **I1** every navigation item (modules, administration areas, rail top entries)
  has an icon key that exists in `LUCIDE_SHAPES`; no two share one (replaces
  `F4.164` L1–L3).
- **I2** expanded, every item renders one `svg.nav-icon[aria-hidden="true"]`
  before its text label, in both shells and all five design systems.
- **I3** collapsed (sidebar and rail), every item shows its icon and no text;
  its accessible name and `title` are its full label (replaces L4).
- **I4** the icon strokes `currentColor` and fills `none`; the `.nav-icon` rule
  reads only the four tokens (no literal size, stroke, colour).
- **I5** DT4/DS1: every design block defines the four tokens, with the values of
  the amendment's table.

Build: `NAV_ICONS` (label → Lucide key) in `navigation-model.ts`; `NavIcon`
renders a key's shapes through an attribute allow-list (as `shapeProps`), in a
24×24 `viewBox`, `class="nav-icon"`.
