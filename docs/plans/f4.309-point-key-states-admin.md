## 1. Goal

`GET|POST /api/v1/admin/point-key-states` and
`PATCH|DELETE /api/v1/admin/point-key-states/:id` list, create, edit and delete
rows of `bms.point_key_states`. Only the global `admin` writes; each write runs
in one `fleetDb` transaction with its audit row (`organizationId: null`). A
seeded pair (`POINT_KEY_STATE_SEED`) answers `seeded: true`; `PATCH` or
`DELETE` of a seeded row, and `POST` of a seeded pair, are 409. `GET
/vocabularies` gains `switchingStates` (key, value, label, tone) for any
signed-in user.

In the web, a Reference Data tab right after Point Keys opens
`/admin/point-key-states`: a table with a "Seeded" badge and no controls on
seeded rows; Add, Edit (label and tone only) and Delete (with a confirm) on the
others. The state legend adds one entry per distinct label and tone. The mimic
code does not change (it reads the rows at read time).

**Out of scope** (decision 7): organization overrides, new tones, editing
seeded rows, non-numeric values, any migration or grant change, a copilot
delete, `index.css` and theme code.

## 9. Open questions for the owner

1. **Who reads the admin list.** (a) Global `admin` only (tab
   `globalAdminOnly`, page fails closed; everyone reads the rows through
   `/vocabularies`); (b) any master-data role, controls hidden for non-admins.
   *Recommended: (a).*
2. **Copilot writes.** (a) No (outside the catalog; a later ADR 0099
   amendment); (b) yes for create and update. *Recommended: (a).*
3. **How "seeded" is detected.** (a) Compare with `POINT_KEY_STATE_SEED`
   exported from `@bms/db`; (b) move the literal to `@bms/shared`; (c) a
   `seeded` column (a migration, which the ADR rules out). *Recommended: (a).*
4. **Tab label and page title.** (a) "State Labels"; (b) "Switching States";
   (c) "Point Key States". *Recommended: (a).*
5. **The `/vocabularies` key.** (a) `switchingStates`, required, fixtures
   updated; (b) optional. *Recommended: (a).*
6. **A legend entry's drawing.** (a) The mimic's switch glyph in its own look;
   (b) a `StatusPill` with tones mapped onto alarm colours. *Recommended: (a).*
7. **The value field.** (a) Any finite number; (b) whole numbers only.
   *Recommended: (a).*
