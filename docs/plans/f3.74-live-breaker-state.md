## 1. Goal (rev 2)

The `lv_single_line` preset draws the SMOC single-line diagram from data: each
breaker node fans out to every member of its role, each member reads its state
from `breaker_main`/`breaker_trip` through a fleet-wide state map
(`bms.point_key_states`), the pipes take an energised / de-energised / unknown
colour from a pure walk over the directed pipes (beside the `F3.32b` freshness
dash, which stays), a CLOSED breaker takes its worst active alarm's colour, a
`breaker_table` widget lists the breakers with their static `rating` /
`trip_cause` asset fields, a mimic on the Overview tab may name the electrical
tab and draw the SLD compactly, "SMOC standard" gains a stock version with
both, a seed demo dashboard at `RSMOC-WC` shows it beside the hand-written
SLD, and the simulator trips one breaker. **A drawn layout gets the same
machinery** (OQ3b): a unit may fan out and may be an energy source, a
`breaker`-symbol unit switches, and "Start from `lv_single_line`" yields a
working SLD layout.

**Out of scope:** operating a breaker (`F3.12`); a state map editor in the
admin UI (rows are seed-owned data for two keys); per-member pairing of fan-out
breakers to loads (a recorded parity difference, §3 D5); moving `RSMOC-WC` off
`builtin` (`F3.75`); upgrading existing site-layout copies to stock v4 (ADR
0088 decision 12: new copies only); the F3.73 audit's binding faults on
CSMOC/PHEWB presets; a `tripped` rule in the automation seed; any change to
`electrical_distribution`; a switching column on layout units (a unit switches
by its symbol, OQ3b).

## 3. Design decisions (against the owner's rulings, §9)

- **D1 `bms.point_key_states` (migration 0097) — OQ1 (a).** Global master
  data like `bms.point_keys`: no `organization_id`, no policy, no FORCE.
  Columns `id uuid PK`, `point_key_code varchar(128) NOT NULL REFERENCES
  bms.point_keys(code) ON DELETE CASCADE`, `value double precision NOT NULL`,
  `label varchar(64) NOT NULL`, `tone varchar(16) NOT NULL`; `UNIQUE
  (point_key_code, value)`; `CHECK (tone IN ('closed','open','tripped'))`;
  `REVOKE INSERT, UPDATE, DELETE ON bms.point_key_states FROM bms_tenant` with
  a `has_table_privilege` assertion. **Rows are seed-owned**
  (`packages/db/src/point-key-states-seed.ts`, after
  `seedPointKeyHeadlineRanks`, `ON CONFLICT (point_key_code, value) DO UPDATE
  SET label, tone`, rowCount asserted = 3): `breaker_main` 0 OPEN `open`, 1
  CLOSED `closed`; `breaker_trip` 1 TRIPPED `tripped`. The table is added to
  `NO_COLUMN`.
- **D1b Layout unit flags (0097, rev 2) — OQ3b "Full".** Folded into 0097
  cleanly: `ALTER TABLE bms.mimic_layout_nodes ADD COLUMN IF NOT EXISTS fan_out
  boolean NOT NULL DEFAULT false, ADD COLUMN IF NOT EXISTS is_source boolean NOT
  NULL DEFAULT false;` and `ALTER TABLE … ADD CONSTRAINT
  mimic_layout_nodes_flags_units_check CHECK (kind = 'unit' OR (fan_out =
  false AND is_source = false))` in a `DO` block (the 0095 shape). Clean
  because: a column add on a FORCE-RLS table changes no row and no policy
  (the two legs stay byte-identical — `tests/f3.32c-…:112-166` keep passing);
  the DEFAULT backfills every row without a `RESET ROLE` write (the 0085
  trap does not apply); the CHECK validation scan is bounded by the table's
  size; and `_kind_fields_check` is not dropped or re-added. Drizzle
  (`mimic-layouts-schema.ts`): `fanOut: boolean("fan_out").notNull().default(false)`,
  `isSource: boolean("is_source").notNull().default(false)`. **A unit
  switches iff its symbol is `breaker`** (no column) — `isSwitchingSymbol`
  in `breaker-state.ts` over `MIMIC_SWITCHING_SYMBOLS = ["breaker",
  "wmpid:breaker", "drawio:circuit-breaker"]` (one constant; N1 ruled yes).
- **D2 Asset fields (0097) — OQ2 (a).** `bms.assets.rating varchar(32) NULL`,
  `trip_cause varchar(128) NULL`; no backfill in the migration (the seed fills
  `CR-Q*`, D11). Exposed on `adminAssetDtoSchema` (`rating`, `tripCause`,
  nullable), accepted `.nullish()` on create/update (omitted = unchanged,
  `null` = clear), two optional text inputs in the asset form.
- **D3 Contracts and pure core (shared) (rev 2).** New
  `contracts/point-key-states.ts`: `pointKeyStateToneSchema = z.enum(["closed",
  "open","tripped"])`, `pointKeyStateSchema { value, label, tone }`,
  `pointKeyStateMapSchema { pointKey, states[] }`. New
  `packages/shared/src/breaker-state.ts`: `BREAKER_ROLE_CODES` (the five),
  `MIMIC_SWITCHING_SYMBOLS`, `isSwitchingSymbol(symbol)`, `BreakerState =
  "offline"|"tripped"|"open"|"closed"|"unknown"`,
  `deriveBreakerState({ stale, points }, maps)`: stale → `offline`; else among
  the points whose value matches a map row, a `tripped` tone wins, then
  `open`, then `closed`; no match → `unknown`. New
  `packages/shared/src/mimic-energised.ts`: `Energy =
  "energised"|"de-energised"|"unknown"`, `SwitchState =
  "closed"|"open"|"tripped"|"unknown"`, **`energiseGraph(graph, switchStates)`**
  where `graph = { nodes: { key, switching, fanOut }[], pipes: { from, to }[],
  sources: string[] }` is built in the web from **either arm's geometry**
  (preset: `def.sources`; layout: units with `isSource`) → `{ nodes, pipes }`
  maps, or `null` when `sources` is empty (no walk — the freshness dash alone,
  as today). BFS from every source over the pipes; a `switching` node passes
  energy when any member is `closed` (OR — OQ4), gives `unknown` when none is
  closed and any member is `unknown` (stale, unassigned, no map) or the node
  has no members, else stops it; every other node passes; joins are OR
  (energised > unknown > de-energised); a non-source node with no inbound pipe
  is de-energised; a pipe takes the energy out of its `from`; cycles are
  guarded by a visited set (a layout may draw one). `worstDownstreamSwitch
  (graph, key, states)`: `tripped > open > unknown > closed`.
  `MimicPresetNode` gains `roleCode: string | null` (OQ8) and `fanOut?: true`;
  `MimicPresetDef.sources?: readonly string[]`. No `switching` or `bus` flag
  on a preset node: switching is the `breaker` glyph (`MIMIC_NODE_GLYPHS`),
  and the bus rule is D6's passive-unit rule, so one rule serves both arms.
