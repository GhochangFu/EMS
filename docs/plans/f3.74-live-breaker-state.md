## 1. Goal

The `lv_single_line` preset draws the SMOC single-line diagram from data: each
breaker node fans out to every member of its role, each member reads its state
from `breaker_main`/`breaker_trip` through a fleet-wide state map
(`bms.point_key_states`), the pipes take an energised / de-energised / unknown
look from a pure walk over the preset's directed pipes, a CLOSED breaker takes
its worst active alarm's colour, a `breaker_table` widget lists the breakers
with their static `rating`/`trip_cause` asset fields, a mimic on the Overview
tab may name the electrical tab and draw the SLD compactly, "SMOC standard"
gains a stock version with both, a seed demo dashboard at `RSMOC-WC` shows it
beside the hand-written SLD, and the simulator trips one breaker.

**Out of scope:** operating a breaker (`F3.12`); a state map editor in the
admin UI (rows are seed-owned data for two keys); fan-out on drawn layouts
`[OQ3]`; per-member pairing of fan-out breakers to loads (a recorded parity
difference, §3 D5); moving `RSMOC-WC` off `builtin` (`F3.75`); upgrading
existing site-layout copies to stock v3 (ADR 0088 decision 12: new copies
only); the F3.73 audit's binding faults on CSMOC/PHEWB presets; a `tripped`
rule in the automation seed; any change to `electrical_distribution`.

## 3. Design decisions (each against its recommended OQ option)

- **D1 `bms.point_key_states` (migration 0097) `[OQ1]`.** Global master data
  like `bms.point_keys`: no `organization_id`, no policy, no FORCE. Columns
  `id uuid PK`, `point_key_code varchar(128) NOT NULL REFERENCES
  bms.point_keys(code) ON DELETE CASCADE`, `value double precision NOT NULL`,
  `label varchar(64) NOT NULL`, `tone varchar(16) NOT NULL`; `UNIQUE
  (point_key_code, value)`; `CHECK (tone IN ('closed','open','tripped'))`;
  `REVOKE INSERT, UPDATE, DELETE ON bms.point_key_states FROM bms_tenant` (the
  0059 posture: catalog rows change by seed/migration, never on the tenant
  pool) with a `has_table_privilege` assertion. **Rows are seed-owned**
  (`packages/db/src/point-key-states-seed.ts`, after
  `seedPointKeyHeadlineRanks`, `ON CONFLICT (point_key_code, value) DO UPDATE
  SET label, tone`, rowCount asserted = 3): `breaker_main` 0 OPEN `open`, 1
  CLOSED `closed`; `breaker_trip` 1 TRIPPED `tripped` — because the FK target
  rows are seed-owned (§2). The table is added to `NO_COLUMN`.
- **D2 Asset fields (0097) `[OQ2]`.** `bms.assets.rating varchar(32) NULL`,
  `trip_cause varchar(128) NULL`; no backfill in the migration (the seed fills
  `CR-Q*`, D11). Exposed on `adminAssetDtoSchema` (`rating`, `tripCause`,
  nullable), accepted `.nullish()` on create/update (omitted = unchanged, `null`
  = clear), two optional text inputs in the asset form.
- **D3 Contracts and pure core (shared).** New
  `contracts/point-key-states.ts`: `pointKeyStateToneSchema = z.enum(["closed",
  "open","tripped"])`, `pointKeyStateSchema { value, label, tone }`,
  `pointKeyStateMapSchema { pointKey, states[] }`. New
  `packages/shared/src/breaker-state.ts`: `BREAKER_ROLE_CODES` (the five),
  `BreakerState = "offline"|"tripped"|"open"|"closed"|"unknown"`,
  `deriveBreakerState({ stale, points: {pointKey, value|null}[] }, maps)`:
  stale → `offline`; else among the points whose value matches a map row, a
  `tripped` tone wins, then `open`, then `closed`; no match → `unknown`
  (decision 3's two-key rule, stated as a tone order so a third key needs no
  code). New `packages/shared/src/mimic-energised.ts`: `Energy =
  "energised"|"de-energised"|"unknown"`, `energisePreset(def, switchStates:
  Map<nodeKey, SwitchState[]>)` → `{ nodes, pipes }` maps, or `null` when
  `def.sources` is undefined (no walk) `[OQ4]`; BFS from every source over a
  DAG; a `switching` node passes energy when any member is `closed` (OR), gives
  `unknown` when none is closed and any member is `unknown` (stale, unassigned,
  no map) or the node has no members, else stops it; every other node passes;
  joins are OR (energised > unknown > de-energised); a non-source node with no
  inbound pipe is de-energised; a pipe takes the energy out of its `from`.
  `worstDownstreamSwitch(def, key, states)` for bus nodes: `tripped > open >
  unknown > closed`. `MimicPresetNode` gains `roleCode: string | null`
  `[OQ8]`, `fanOut?: true`, `switching?: true`, `bus?: true`;
  `MimicPresetDef.sources?: readonly string[]`.
