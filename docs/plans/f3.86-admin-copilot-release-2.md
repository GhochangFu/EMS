## 1. Goal

Build release 2 of the administrator copilot as ADR 0099 decides it: the master-data write routes (locations — with their Control Room view and site-layout sub-routes (ruling Q7(b)) —, RTUs, assets, asset groups with member add/role/remove, point keys, asset points) become catalog entries with stepper wizards; users and grants become `risk: "access"` entries with the temporary password typed on the Confirm card as a `clientOnly` field, ADR 0089's checks called (never copied), the global `admin` role never proposed, grant revoke and group-member removal as the only two `DELETE` entries each with a red Confirm, and an access change proposed only when the admin's own message asked (ruling Q3); and the onboarding agent becomes a copilot skill — draft steps free, one commit Confirm bound to the draft hash through `commitProposed`, the typed phrase replaced by the Confirm button, the copilot switch and daily limit applying to it (ruling Q4) — after which `/admin/onboarding` retires (ruling Q5).
