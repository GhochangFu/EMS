## 1. Goal and out of scope

**Goal.** Every remaining stock-palette and `bms-*` colour class in `apps/web/src` (2,997 uses in 137 files) becomes a role class from the 41-role vocabulary of `apps/web/src/index.css`, so that the whole SPA follows `data-theme` once `F3.65c` makes the switch visible. 2,273 uses (75.8 %) are exact rewrites whose light pixel does not move (held by mapping-table M2/M2b); 618 (20.6 %) carry a class whose role depends on context and are resolved by the rules in §2.4 (81 of them by one automatic rule, 5 by a hand table); 106 (3.5 %) are the merged shades the owner accepted at the `F3.65a` gate, listed site by site in §2.3. The two stray hex sites of R-b become roles. `FLOOR` ends with `palette 0` in every file, a new hard-zero case refuses any palette class, and only the 16 `F3.65c` hex/func files keep a row.

**Out of scope.** The 188 remaining hex literals and 2 colour functions (`F3.65c`: CRAC/SLD/SMOC/world-map SVGs, `formula-editor.tsx`, the four ECharts components, `health-summary-donut.tsx`, `WIDGET_TONE_COLOR`, the login hero); the visible Light/Dark control; deleting `bms.*` and the stock palette from `tailwind.config.js` (`F3.65c`, ruled F3.65a OQ4); emptying `FLOOR` (`F3.65c`); any restyle beyond the ruled merges; `AGENTS.md` wording. No contract, no route, no migration — `packages/shared/src/contracts/` is untouched, so §4.8 / ADR 0030 do not apply.

## 3. Design decisions

- **D1 — A codemod does the mechanical 2,273 + 613 rule-resolved sites; the hand table does 9.** `scripts/codemods/f3.65b-role-classes.mts` (new directory), run with `npx tsx`, imports `roleFor`, `SHADE_ROLES`, `CLASS_OVERRIDES` from `tests/support/colour-role-map.ts` and the scanner's regex from `tests/support/colour-scan.ts`, so the mapping has **one source of truth** and the codemod can never disagree with M4. It is one-shot: committed in this PR so the review can re-run it, deleted by `F3.65c` (its docblock says so). Not CI-wired — the gates hold the result; its own fixture test (U1) runs in the `repo` project. Output through `process.stdout.write` (the pre-commit hook refuses `console.log`). It is listed in `typecheck:tests` by `pnpm pkg set`.
- **D2 — Rewrite rule per match.** `colour-scan.ts` exports `paletteClassMatches(src): { index, className }[]` (`paletteClasses` becomes its `.map`) and `classStrings`. For each match on the comment-blanked text (offsets preserved — `blankComments` replaces comment characters with spaces; verify in U1): keep the variant prefix; split `className` into utility, shade and `/NN|/[…]`; `role = roleFor(className).role`, then the context rules: `text-white` → `on-accent` iff a token `^(\S*:)?bg-(bms-green(-dark)?|accent(-strong)?)$` is in the same class string, else `on-dark` (logged for review); `bms-green` under a `focus`/`focus-visible` variant → `focus`; a row with `compareOver` → `<utility>-<role>/<alpha×100>`; a `HAND` entry `{ file, line, from, to }` wins over every rule and **throws if `from` is not on that line**. Replacement = `${utility}-${role}${opacity}`. Arbitrary values (`bg-[#F7F8FA]`) are not palette matches and are hand edits. Spec/test paths are refused.
- **D3 — The codemod proves it changed nothing else.** After a rewrite it asserts: the whitespace/quote token stream of old and new source has the same length and differs only at logged indices; every logged exact rewrite satisfies `resolveTailwindShade(shade) === lightHex(role)` (M2 per site); the per-file rewrite count equals the file's `FLOOR.palette`; every emitted role is a key of `parseTokenBlocks(index.css).light`; a second run is a no-op; `paletteClassMatches(new) = []`. Its log prints the merged sites as §2.3's table and the `text-white → on-dark` sites — the PR body pastes both.
- **D4 — Hand table (9 entries), applied by the codemod, not by an editor:** `system-status-indicator.tsx:49` `bg-white/40→bg-on-dark/40`; `rules-panel.tsx:407` `bg-white→bg-on-dark`; `asset-templates-page-tab-strip.tsx:65` `text-white/80→text-on-accent/80`; `crac-page.tsx:96` and `sld-page.tsx:92` `bg-gray-200→bg-well-deep`; `report-schedules.tsx:513` and `reports-panel.tsx:395` `bg-bms-ink→bg-chrome` (OQ3, recommended); `scoped-action-link.tsx:17` and `rules-panel.tsx:72` `text-gray-500→text-neutral-ink` (OQ4, recommended). The last four are also recorded in `CLASS_OVERRIDES` as merged rows (`bg-bms-ink → chrome, ΔE 1.27`; `text-gray-500 → neutral-ink, ΔE 17.65`) so M3b holds their ΔE and `roleFor` agrees with the tree — `text-gray-500` has exactly those two uses; `fill-gray-500` (4) keeps `ink-faint`.
- **D5 — The two stray hex sites.** `tank-level-widget.tsx:57` `stroke="#8A94A6"` → `className="stroke-ink-hint"` (attribute removed; nearest role, ΔE 5.43 — `ink-hint` is the ruled "faint strokes" role; `ink-faint` 12.4, `line-strong` 18.8). `sld-page.tsx:160` `bg-[#F7F8FA]` → `bg-well` (ΔE 0.66; `canvas` 1.04, `well-deep` 0.82).
