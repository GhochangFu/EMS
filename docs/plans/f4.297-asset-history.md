# F4.297 — Asset history screen: step-3 plan (ADR 0108, decision for F4.297)

## Goal

One screen, `/assets/:assetId/history`, reached from an asset in the Assets list, a Control Room asset row or card, and an alarm row. It lists the asset's points with the latest value and poll time; for up to 8 chosen points it shows a chart and a bucket table over a preset range (15 min, 24 h, 7 d, 30 d, 1 y) or a custom from/to, with min/avg/max per bucket, the rollup level used, and a compare with the previous period of equal length (dashed overlay); and for the chosen point it shows a table of the latest raw records (time, device time, value, unit) with a "load older" cursor. This row owns the `aggregate` contract change (custom `from`/`to`, compare buckets, per-bucket stats) that `F4.301`–`F4.303` reuse, and one new raw-records read. Every read runs `canReadAsset` before it touches `telemetry.*` (no RLS there).

**Out of scope:** export, pin, share link, schedule (`F4.303`; the page keeps its state in the URL so `F4.303` can reuse it); a per-asset batch aggregate route (measured unnecessary, below); any new rollup level or retention change; the `recent` route's missing try/catch (a 500 on a malformed ref — flag as a follow-up row, not fixed here); "Today"/"This month" presets (`F4.298`; this page's presets are trailing, but it shows every time in the site zone, ADR 0108 §1.9).

## Measurements and builder calls (from the running stack and the source)

| Question | Measured | Call |
|---|---|---|
| Batch read per asset vs N `aggregate` calls | `bms.asset_points`: max **16** points per asset, mean 4, 187 assets with points, 206 assets (compose stack, 2026-10-31) | **No batch route.** The chart reads at most `MAX_WIDGET_POINTS` = 8 points → ≤ 8 parallel `aggregate` calls, each one SQL statement and one `canReadAsset`. A batch route is a second contract for a cost that does not exist at this scale. `F4.299` re-measures for its own scale. |
| Latest value + poll time for the point list | `at-instant` takes ≤ 50 refs, any age; `latest` caps `windowMinutes` at 60 so a stale point is absent | **`fetchPointValuesAt(refs, nowIso)`**, chunked by 50 (one call for every asset today). The list must show "last poll 3 days ago", which `latest` cannot. |
| min/avg/max per bucket | `bucketSql` returns one function per call | **New optional query flag `bucketStats=true`** adds `min`, `average`, `max`, `sampleCount` to each bucket. Three calls per point × compare would be 48 reads of up to 2,880 rows for 8 points. |
| Raw records table | `/recent` is window-shaped (newest 5,000 in ≤ 7 d), has no `deviceTime`, no cursor; `telemetryReadingSchema` is the ingest/socket shape used by 38 files | **New route `GET /telemetry/points/:pointRef/raw?limit=&before=`** with its own contract. A point that stopped 10 days ago would show an empty `/recent` table; widening the socket shape for one table column is the wrong seam. Index `point_values_point_asset_time_idx (point_key, asset_id, time desc)` serves `ORDER BY time DESC LIMIT n` with `time < $before`. |
| Compare bucket alignment | 1 h / 1 d buckets are UTC-aligned; `to = now` leaves a partial last bucket | Server returns **true timestamps** for compare buckets. The client shifts each by `+span` for the overlay. The partial last bucket is shown as is; the level and the window ends are printed under the chart. |
| Timezone | No web helper formats in a site zone; `peakLabel`/`formatTime` use browser local time; the asset list carries no zone and a scoped user cannot read `/admin/locations` | **Owner ruling: an asset page is a site view** (ADR 0108 §1.9). The asset's location `timezone`, else its organization's; a stored `UTC` → `Etc/UTC`; an invalid stored zone falls to the next link. The `aggregate` response carries it as `timeZone`, resolved by the server after `canReadAsset` with the shared chain function `F4.298` U1 declares. Every time on the page and the custom `datetime-local` inputs use it. No browser-local time. |
| Escalation | A custom `from` older than 735 d with span ≤ 48 h picks `1m`; `levelForRange` escalates to `1h` (5m has the same horizon) | Reachable now. `bucketSeconds` already reports the real level; the page shows it. Guards and prose are updated (U2). No new `coarsened` field (YAGNI). |
