# F4.305 — the trend strip as a dashboard widget (ADR 0108 Amendment 3)

Step-3 plan. Scope: ADR 0108 Amendment 3 (`main` at `51475211`, #974). Builds on `F4.301` (#973, `dd0cab45`). Row 🟡, P1, not a ⭐ enabler.

## Owner answers (2026-11-01)

1. **Config by tab key** (C1), not by group uuid: `{ tabKey?, defaultRange }`; no `tabKey` = the whole site, a `tabKey` = the group that tab of the same dashboard binds. This refines Amendment 3 item 2's drafter line.
2. **The once-per-copy stamp is a new nullable column `bms.dashboards.stock_version integer`** in the same migration `0118` (C5). The seed copy and the API copy action both write it.

## 1. Goal

Add a thirteenth widget kind, `trend_strip`, that draws the `F4.301` trend strip on a dashboard canvas: the same component, the same one read (`GET /control-room/sites/:locationId/trend-strip?range=&assetGroupId=`), the same click to `/asset-history/:assetId?range=&points=`. An administrator adds it from the widget picker, scopes it to the whole site or to one asset group (through the tab that binds the group), sets a default range, and moves, resizes or deletes it like any widget. Stock site layout **v5** puts one on every tab directly under the top row of tiles; the seed's upgrade chain gains a **v5 step** that inserts one strip under the top tile row of **every** tab of every seed-owned copy — edited tabs included — moves the widgets below it down by the strip's height, overlaps nothing, and runs **once per copy** by a stamp, so a strip an administrator deletes stays deleted. The wall shows it. `SiteDashboardView` drops its fixed strip (no tab shows two); `GeneratedSiteView` moves its fixed strip directly under the KPI tile row; the built-in SMOC Main Dashboard keeps its strip.

**Out of scope.** No new route, query schema, telemetry statement, grant, RLS change or dependency. No guided wizard (`F4.306`). No change to the strip's series rule, caps, level, zone or budget (Amendment 2 items 1–8). No strip on the five hand-drawn SMOC mimic tabs. No per-widget point list or source. No change to the `F4.297` history page.
