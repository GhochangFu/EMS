# F4.315 + F4.316 — plan: the live-check fixes, and an asset label that names its RTU

Written by plan-architect (Fable), 2026-11-06, against `docs/adr-f4-315-316` at `578e4bd8` (= `main` `9d86d25a` + the three ADR texts). CodeGraph's shell binary is not on PATH in this session (`codegraph: command not found`) and the MCP tool was not surfaced; every measurement below is from ripgrep and the files themselves, with file:line evidence.

## 1. Goal

**F4.315** — five small fixes the `F4.312`–`F4.314` live checks found: (1) the adoption wizard's "This adoption is refused …" sentence sits *above* the refusals it points to, and the Review step of every catalog wizard stops printing its heading twice; (2) the copilot gains the read tool `list_asset_templates`, and an adoption refusal names its cause when the caller may see the records (ADR 0099 Amendment 14); (3) "Inputs valid for" gets a default (300 s streaming, 2 × interval scheduled) and the Schedule step refuses Next while it is empty — Add panel and bulk wizard only; (4) **New key** gains a Domain field, pre-filled with the asset's domain (bulk: the shared domain), sent as `domain` on the existing `POST /admin/point-keys`; (5) Suggested formulas on a published or archived Calculations tab render with **Use this formula** disabled and the reason given (ADR 0109 Amendment 2).

**F4.316** — every surface that names an asset names it `<code> · <RTU display_name>`, or `<code> · <location name>` when the asset has no RTU (ADR 0111 C1–C4). Each shared response schema that names an asset by code gains two additive required-nullable fields, `assetRtuName` and `assetLocationName`, filled by the same two LEFT JOINs everywhere; one pure formatter in `@bms/shared` is used by the web, the report/export writers and the copilot. The `· <where>` part wraps and is never truncated; CSV/XLSX keep the code column and add a label column.

**Out of scope.** Search and filters (ADR 0111 decision 6); rewriting asset names (the PHE rename stays); the fixed SVG labels of the SLD/CRAC schematics (`apps/web/src/components/live-svg/sld-bindings.ts:14-19`, demo constants, not DTO-driven); the mapping-sheet export (`asset_code` is the sheet's round-trip key, `apps/api/src/admin/asset-points/mapping-sheet-export.ts:18`); the copilot's `pointKey.create` path (Amendment 2 decision 3); the override wizard's empty age (= inherit, decision 2); any migration or new dependency (none; §11).
