## 3. Design decisions settled at this gate

1. **The tariff is resolved per asset in the read's scope, at the nearest scope, through the shipped resolver** (Q4). Both reads group the cagg rows by `asset_id` in a `per` CTE; a second statement over the same CTE returns `(asset_id, kwh, currency)` per asset with energy in the window (`JOIN bms.assets a JOIN bms.organizations o`; both services already run on `FLEET_POOL`). `CalcParametersService.resolveForAssets(ids.map(id => ({ assetId: id, key: "energy_tariff_per_kwh" })), end)` — organization row for everyone, location row where one exists, asset row where one exists — contains decision 7's sentence and adds nothing the store cannot express. `end` is `new Date()` for the dashboard, `range.end` for the report.
2. **Fail closed, three ways, in one pure function** — `energyCost(rows, tariffs)` in `apps/api/src/telemetry/energy-cost.ts`: `currency` = the one distinct currency of the rows, else `null`; `tariffPerKwh` = the one distinct resolved tariff when every row resolved, else `null`; `indicativeCost` = `Σ kwh_i × tariff_i` (2 dp) when every row resolved and `currency` is non-null, else `null`; no rows → all `null`. Measured consequence: `admin@bms.local`'s fleet spans `ESKOM` (ZAR, 100 assets) and `PHEWB` (INR, 50) — the dash whenever both have energy in the window; the §4.6 claim uses `wc-admin@bms.local`. `tests/adr-0070` part (g) scans the helper for `COALESCE(`, `?? 0`, `?? 1`.
3. **The DTO change, made once.** `energyCentreSummarySchema` (`contracts/operations.ts:16`): `indicativeCost: z.number().nullable()`, `tariffPerKwh: z.number().nullable()`, `currency: z.string().nullable()` — plain keys on the existing `z.object`, **no `z.intersection`, `.merge()`, `.extend()`, `.readonly()`**. `energyReportPreviewSchema.summary` reuses it. `adminOrganizationDtoSchema` gains `currency: z.string()` — **997 → 998 of the 1000 cap**.
4. **`DashboardModule` and `ReportsModule` import `CalcModule`** (which exports `CalcParametersService`); constructors take `@Inject(CalcParametersService) private readonly parameters: Pick<CalcParametersService, "resolveForAssets">` so the seven existing `new DashboardService(pool)`/`new ReportsService(pool)` spec sites pass a two-line fake. The worker root imports neither. **A green build is not a DI gate** — boot the API in U17.
5. **Money points carry `unit: ""`** (Q8), the spelling `pf`/`pue` use for "no unit"; the label names the organization's currency.
6. **Every windowed formula is self-contained** — the window read is inline, never read from a derived sibling; `E4.1b` design decision 9 dedupes identical reads per sweep, so it costs nothing and no point inherits a sibling's `window_empty` as a `stale_input`.
