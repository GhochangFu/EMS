## 1. Goal

Add a seventh vendored mimic symbol library, **`iso`** ("Isometric", `fill` style,
`sort_order` 80): the owner's 50 isometric thin-line glyphs — the 29 core symbols, the
flow meter and RTU panel, and 19 equipment kinds — drawn with the anatomy kit (MIT) and
built in the repository from committed glyph scripts and a vendored, unchanged copy of
the two kit files (ruling 1). `generate.mjs --iso` writes the shared and web generated
modules and the migration rows the `0092` way; one migration (next free number at build
time) inserts the library row and 50 symbol rows; every organization sees the library
(decision 4, no code: `coalesce(enabled, true)` already exists) and it loads lazily like
`qet`/`wmpid`/`drawio`. A **`glyphSet: "core" | "iso"`** field on both arms of
`mimicConfigSchema` (default `core`, no migration) makes a preset or layout mimic draw
`iso:<key>` for every unit whose symbol is a core key (decision 5); the isometric tank
keeps the live level fill through a generated level box (decision 6). The mimic widget's
settings form gets a "Glyph set" select.

**Out of scope.** Per-part motion, a per-organization default glyph set, isometric
versions of tabler/lucide/mdi icons (ADR 0121 Deferred); any change to the shape
grammar, the upload parser, the API (no new route; the settings route already takes any
library code), the layout editor's behaviour (it draws `iso` units still — ADR 0120
decision 6 is F4.344's); retiring organizations' uploaded copies (owner task after
deploy); a redraw of any glyph (the 50 modules are the owner's drawings and are moved,
not edited — except `tank.mjs`, which gains one exported constant, §5 T1.3); any
AGENTS.md edit.

- **R3 — `--iso <dir>` is the fill output directory.** `load(dir)` reads
  `<dir>/../manifest.json` → `{ version: "1", line: 40, kit: { "iso-kit.mjs": sha,

  children with only `d`, and returns `[["path", { d: bakePath(d, normaliseTo24(viewBox)) }]]`

  `Own work; anatomy kit MIT` (25 chars ≤ varchar(64)), attribution_url
  `https://github.com/wheresryan22/anatomy`, style `fill`, sort_order 80. (Q8)
- **R5 — the tank's level (decision 6): a generated ellipse box, no clipPath.** `tank.mjs`
  exports `level = { r: 14, z0: 0, z1: 34 }` (its `SHELL`). `build.mjs` projects it with the
  glyph's own `P`: `[cx, bottom] = k.iso([0,0,z0], P)`, `top = k.iso([0,0,z1], P)[1]`,
  `rx = r·cameraOf(P).k − half`, `ry = rx·sinE`, `half` = the ribbon half-width, so the fill
  sits inside the lines; the generator maps it through the same `normaliseTo24` matrix and
  writes `apps/web/src/components/widgets/mimic-symbol-libraries/iso.level-boxes.generated.ts`
  — `ISO_LEVEL_BOXES: Readonly<Partial<Record<IsoSymbolKey, MimicLevelBox>>>`, numbers only,

  pure `isoTankLevelPath({cx,rx,ry,top,bottom}, fraction)` returns

  with `yf = bottom − fraction·(bottom − top)`: the back arc of the liquid surface, the
  right side, the front arc of the floor, close — the core `tankFillPath` with an
  elliptical top. No `<clipPath>` id (two mimics on one dashboard must share no id). (Q5)
