## 0. Goal and out of scope

**Goal.** Give the API an S3-backed object store behind one DI token, a `bms.asset_images` tenant table, two authenticated read routes (`GET /api/v1/assets/:assetId/images`, `GET /api/v1/assets/:assetId/images/:imageId/content`), a `storage` section on `GET /health`, MinIO in the compose stack and CI, and one integration spec that proves `putObject → row → GET …/content` end to end — decisions 1–11 of `docs/adr/0066-object-storage-and-asset-images.md`, nothing more.

CREATE TABLE IF NOT EXISTS bms.asset_images (

CREATE INDEX IF NOT EXISTS asset_images_asset_created_idx ON bms.asset_images (asset_id, created_at DESC);
ALTER TABLE bms.asset_images ENABLE ROW LEVEL SECURITY;
ALTER TABLE bms.asset_images FORCE ROW LEVEL SECURITY;

CREATE POLICY tenant_isolation ON bms.asset_images
