## Goal and out of scope

**Goal.** Every place a user reads the product name reads `Verve`: the SPA header, rail, footer, login
page, auth callback, tab title and favicon, two appearance labels; the report e-mail sentence, the
test notification, the OpenAPI and Swagger titles, both assistant prompts; the realm display name.
The header, rail and login hero show the traced pulse-V logo as inline SVG from one data module. The
tagline is one constant. The F3.33 gate is inverted and holds the rename, the logo's paint and the
asset copies.

**Out of scope.** Any new npm package, web font, schema change or migration; a per-organisation
display name; renaming the keys `nexus` / `nexus-soft`, any code symbol or file; header layout or the
`xl` breakpoint; a `mark` variant of `Wordmark` (no shell has a logo slot in a collapsible sidebar at
`f57b23cc` — the logo sits in the header in both shells; the tile ships as the favicon only); the
tagline SVG files in the web (docs only); a new colour role or contrast pair; changes to
`build-logo.py`; past ADRs, plans and backlog rows; `deploy/aws/setup-server.sh:96`
(`DEMO_PASSWORD=Nexus-…`, a password prefix); the `chore(agents):` sweep; Keycloak on an existing realm.
