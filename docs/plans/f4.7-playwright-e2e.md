## 1. Goal and out of scope

**Goal.** Add a private workspace package `apps/e2e` that runs five Playwright specs on Chromium against the built web bundle (`vite preview`, 127.0.0.1:5173, local auth) and the API from source (:4000, `AUTH_MODE=local`), on Postgres/Timescale + Redis + `apps/sim`. One spec drives the login form; the other four start from a per-run `storageState`. A new workflow `.github/workflows/e2e.yml` runs the suite when a PR gets the `e2e` label or on manual dispatch. `pnpm test` / `test:coverage` never collect it. `pnpm typecheck:tests` type-checks it.

**Out of scope.** OIDC login (`F4.253`); the copilot path (ADR 0100 decision 8); Docker images (the served-image check stays at step 6); Firefox/WebKit; any change to `AGENTS.md` (a later `chore(agents):` PR); any API response contract (§4.8 / ADR 0030 contract work is **N/A**); a reusable workflow shared with `ci.yml` (YAGNI; the five DB steps are copied).

**Q1 — an ACTIVE alarm in the run.**
- The alarm engine runs **in the API process**: `AlarmEngineService.onModuleInit` subscribes to the hub (`apps/api/src/alarms/alarm-engine.service.ts:62-68`); the hub is fed by `LISTEN bms_telemetry` (`apps/api/src/telemetry/telemetry-listener.ts:77`). In `apps/sim/src/index.js`: CR-* assets re-centre voltage on 230 each tick (`:369`); non-CR voltage walks from 228–236 in [220, 240] step 0.4 (`:154, :369`) — stochastic; non-CR `kw` is at most ≈ 61.8 (`:370-374`); the `pf` walk floor is 0.82 (`:373`); `breaker_main` opens with p = 0.002 per tick (`:382`).
