Plan by `plan-architect` (Fable), 2026-09-26, from ADR 0076 decision 9, gate questions 13 and 14, Order 10–11, and the `F3.70` row. Measured read-only at `dd89de9f`. Scope gate: passed. Merge approval (step 7) is still owed.

## Owner rulings (2026-09-26)

- **OQ1 — how the tabs render: (a).** The site page hosts a tab strip and renders the chosen page's *content*: the seven `ControlRoom<X>Content` components are exported, one shared `SchematicTelemetryProvider` serves all tabs, and the `AppShell` page wrappers are deleted.
- **OQ2 — a tab outside an asset-group scope: (iii).** The site header and the allowed tabs stay; the body shows "Outside your asset-group scope"; the content never mounts. Default tab: `overview`, rendered in place at the bare site URL.
- **OQ3 — the `/cr-*` redirect target: (a).** `code: z.string()` is added to `locationKpiSummarySchema`; the client finds `SMOC_SITE_CODE = "RSMOC-WC"` in the readable KPI list.
- **OQ4 — a caller who cannot read RSMOC-WC (or whose read fails): lands on `/control-room`** (level-skips into their own organization). The seven redirect routes stay inside `ControlRoomScopeRoute`, so `none` lands on `/`.
- **OQ5 — a tab URL on a non-`builtin` site, or an unknown tab: `<Navigate replace>` to the bare site path**, which renders the site's current view.
- **OQ6 — the seven page files: (b) move them** with `git mv` to `apps/web/src/components/control-room/smoc/` in a final unit (U6), updating every path reader (the two repo-invariant suites, imports, AGENTS.md is the post-merge sweep's).

## Decisions (engineering)

- **D1** — the host renders the content (OQ1); the content's own `PageHeader` stays below the site header.
- **D2** — one route `:tab?`; `smocTabFromParam(undefined)` = `"overview"`, an unknown value = `null`.
- **D3** — the per-area rule is keyed by tab: `SMOC_TABS` `{ key, label, area }`; `allowedSmocTabs(scope)` filters through `canAccessControlRoomArea`. `routeArea` and `canAccessControlRoomPath` die with their last caller.
- **D4** — a disallowed explicit tab renders the scoped-out card under the allowed strip (OQ2).
- **D5** — a tab segment on a non-`builtin` site, or an unknown tab, redirects to the bare site path (OQ5), decided only after both reads have data.
- **D6** — `SmocLegacyRedirect` decides from `data`, never from `status`: pending → a status line; RSMOC-WC readable → the tab; not readable or read failed → `/control-room` (OQ4).
- **D7** — the redirect finds the site by `code` (OQ3); `code: z.string()` is a plain additive field on the flat `z.object`; the API selects `l.code` and adds it to `GROUP BY`.
- **D8** — seam with F3.69 (above).
- **D9** — tab labels without the `CR ·` prefix; the strip is `<nav aria-label="SMOC pages" data-testid="smoc-tabs">` of `Link`s with `aria-current="page"` on the active one.
- **D10** — the seven files move to `components/control-room/smoc/` (OQ6), in U6, after the behaviour is green.
