## 0. Goal, and what is out

**Goal.** An organization owns symbol libraries. Migration `0093` creates `bms.mimic_org_symbol_libraries`, `bms.mimic_org_symbols` and `bms.mimic_library_settings` in the `0088` shape (`organization_id NOT NULL`, `ENABLE` + `FORCE ROW LEVEL SECURITY`, the strict `tenant_isolation` policy in `USING` and `WITH CHECK`, no `NULL` disjunct, privileges from `0041`'s default grants), adds `mimic_layout_nodes.org_symbol_key varchar(64)` with the composite foreign key `(organization_id, org_symbol_key) → bms.mimic_org_symbols (organization_id, key)` and replaces `mimic_layout_nodes_kind_fields_check` so a unit has exactly one of `symbol` / `org_symbol_key`. An organization key is `org.<library code>:<name>` on the wire in a node's `symbol` and `org.<code>` in `symbolLibraries`; the contract widens to accept both (decision 2), the service maps the key to `org_symbol_key` and back (decision 3). An administrator (`admin` for any organization, `organization_admin` for its own) creates and retires organization libraries, uploads one SVG per symbol through `POST /api/v1/mimic-symbol-libraries/:id/symbols` (multipart, 64 KiB, `image/svg+xml`, at most 500 symbols per library), parsed by `saxes` into geometry only — never sanitized text — with the refusal list and the dropped editor metadata of decision 6, and sets the per-organization switch for a global library (`PUT /settings/:libraryCode`; `core` cannot be disabled; no row means enabled). A save refuses a newly chosen disabled or retired library and a newly placed inactive symbol, except what the stored version of the same layout already has (decision 5). The layout `GET` and the dashboard resolver embed `orgSymbols` (key, label, style, `viewBox`, shapes) so a viewer needs no library endpoint; stored shapes are re-checked by the Zod contract on the way out and the renderer copies only allowlisted keys into props (decision 6). The web gains a library-management page, the editor's palette and inspector read organization symbols from the API, and the attributions page (slice 1) lists the organization's own libraries.

**Out.** Third-party sources (slice 2); the attributions page itself and the carried fixes for global symbols (slice 1 — this slice only extends them with `org.` keys); a hard `DELETE` route for a library or a symbol (decision 7: `active = false` retires; the foreign key refuses a delete, and no route exists to try); a sanitizer that rewrites text; storing or serving the raw SVG; symbol upload for a global library; a `/vocabularies` field for libraries; any change to presets, seeds, `AGENTS.md` §6, `0088`–`0092`; the F3.71 Tailwind conversion (plain classes as today).
