## 1. Goal

The live mimic widget animates each unit's **whole glyph by its state**, in the
renderer only: a `tripped` breaker (any fan-out member) **blinks** (1.0 s), an
`alarm` unit whose top alarm's tone is `critical` **pulses fast** (0.8 s), any
other `alarm` **pulses** (1.6 s), a `live` unit **breathes** (3.2 s); `stale`,
`none`, `unassigned`, a unit with no asset, a passive unit and every other
breaker state stay still. Only opacity (and, for a pulse, a 6 % scale about the
glyph's centre) moves — colour stays the ADR 0078 role class. A pure
`mimicGlyphMotion(status, topAlarmTone, breakerStates)` in `lib/mimic.ts`
decides; the scene passes the answer to `MimicGlyph` (and to `BreakerSwitch`,
which draws the tripped contact in the glyph's place), which emits `data-motion`
and a `motion-safe:animate-mimic-*` class whose keyframes live in
`tailwind.config.js`. Reduced motion always wins (Tailwind `motion-safe:`). A
per-widget `motion?: boolean` on both `mimicConfigSchema` arms (absent = on, no
migration) and a "Glyph motion" checkbox in the widget inspector turn it off.
Nothing moves in the layout editor, the symbol palette, the preset / copilot
previews, the editor's "Preview with site", or the static builder tile.

**Out of scope.** Per-part motion (impellers, fan blades — an ADR 0086
amendment), a true "running" state, acknowledged-vs-unacknowledged flashing, an
organization-wide switch (ADR 0120 Consequences); any change to the symbol
grammar, the upload parser, stored symbols, the mimic API responses or the
database; the pipe dash (`FlowDash`, unchanged); the `iso` library and
`glyphSet` (F4.345, ADR 0121); any AGENTS.md edit.

## 3. Drafter refinements (ADR 0120 lines marked *(drafter)*)

- **R1 — the function (decision 2).**
  `mimicGlyphMotion(status: MimicNodeStatus, topAlarmTone: string | null, breakerStates: readonly BreakerState[]): MimicGlyphMotion`
  with `type MimicGlyphMotion = "blink" | "pulse-fast" | "pulse" | "breathe" | "none"`.
  Order: any `tripped` → `blink`; `alarm` + tone `=== "critical"` → `pulse-fast`;
  `alarm` (any other tone, `null` included) → `pulse`; `live` → `breathe`; else
  `none`. It takes the **raw** `topAlarm.tone` (the vocabulary tone), not
  `mimicAlarmTone`'s collapsed callout colour, so no severity code and no colour
  mapping is involved. The scene passes `(breakersOf.get(key) ?? []).map(m => m.state)`
  for every roled unit — one expression covers single, fan-out and non-switching.
- **R2 — the inner wrapper (decisions 1, 3).** `MimicGlyph` keeps its positioned
  `<g data-testid="mimic-glyph">` untouched and wraps its *content* in
  `<g data-testid="mimic-glyph-motion" data-motion={motion} className={MIMIC_GLYPH_MOTION_CLASS[motion]}>`
  — **only when `motion !== "none"`**. A still glyph renders byte-for-byte as
  today, so every existing DOM claim (incl. `glyph.children`) and every
  editor / palette render stays identical. One helper,
  `motionWrap(motion, children)`, exported from `mimic-glyphs.tsx` and used by all
  four draw paths and by `BreakerSwitch`'s contact.
- **R3 — classes.** `MIMIC_GLYPH_MOTION_CLASS: Readonly<Record<Exclude<MimicGlyphMotion, "none">, string>>`
  in `lib/mimic.ts`, full literals (the `MIMIC_GLYPH_FILL_CLASS` precedent):
  `blink: "motion-safe:animate-mimic-blink"`, `breathe: "motion-safe:animate-mimic-breathe"`,
  `pulse: "motion-safe:animate-mimic-pulse origin-center [transform-box:fill-box]"`,
  `"pulse-fast": "motion-safe:animate-mimic-pulse-fast origin-center [transform-box:fill-box]"`.
  `origin-center` and the arbitrary property are harmless without the animation,
  so they need no variant.
- **R4 — opt-in at the component, on-by-default in the config (decisions 5, 6).**
  `MimicScene` and `MimicWidget` gain `motion?: boolean` **defaulting to `false`**;
  only `MimicWidgetLive` passes `motion={widget.config.motion !== false}` (PR 1
  passes `motion` unconditionally until the field exists). Every other caller —
  editor canvas, palette, previews, **"Preview with site"**, static tile — passes
  nothing and is still by construction. (Q2)
- **R5 — the tripped contact blinks (decision 2).** A single switching unit with a
  state draws `BreakerSwitch`, not the glyph, so `BreakerSwitch` takes
  `motion?: MimicGlyphMotion` and wraps its contact paths with `motionWrap`; its
  `unknown` branch passes `motion` to `MimicGlyph`. A fan-out unit's **unit glyph**
  blinks; the member rows' small switches never receive a motion (ruling 1: whole
  glyph, one motion per unit). (Q4)
- **R6 — three keyframes, four utilities (decision 7).** `mimic-blink`
  (`0%: opacity 1` · `50%: opacity .15`, `1s step-end infinite`), `mimic-pulse`
  (`0%,100%: opacity 1, transform scale(1)` · `50%: opacity .45, transform scale(1.06)`),
  `mimic-breathe` (`0%,100%: opacity 1` · `50%: opacity .7`, `3.2s ease-in-out infinite`);
  `animation["mimic-pulse"] = "mimic-pulse 1.6s ease-in-out infinite"` and
  `animation["mimic-pulse-fast"] = "mimic-pulse 0.8s ease-in-out infinite"` share
  the keyframe. (Q3)
- **R7 — `motion: false` is the only stored value.** `buildMimicConfig` writes
  `motion: false` when the row's `mimicMotion === false`, else nothing; `true` and
  absent both mean on and are written absent (the `compact` idiom, inverted).
  Both arms. (Q6)
- **R8 — uniform wrapping.** The loading skeleton and the fallback `unit` wrap
  too (one rule: the glyph's content moves by state whatever draws it); the
  skeleton's `animate-pulse` on the outer `<g>` is unaffected. (Q7)
- **R9 — the WCAG and reduced-motion proofs are a `tests/` invariant** over
  `tailwind.config.js` and the compiled CSS (jsdom computes no media query and no
  `animation-name`), plus the §5 browser read.
