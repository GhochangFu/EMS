## 0. Goal, and what is out

**Goal.** Three small, independent fixes that ADR 0086 carries from the `F3.32e` reviews, plus the attributions page. (1) **Decision 5 / 10a–b:** a save refuses a unit whose symbol is inactive in `bms.mimic_symbols`, and refuses an inactive library — **except** a library or a unit symbol that the stored version of the same layout already has (the retired-role rule, which `assertRolesLive` already implements for role codes). The canvas still draws a stored retired symbol (already true: the renderer has no active flag; gated by a new integration claim). (2) **Decision 10c:** the read path drops a `mimic_layouts.symbol_libraries` code that the contract does not know and logs it, so one bad row no longer fails the whole list response in the web client's `checkResponse` (dev/test throw on `invalid_enum_value`). (3) **Decision 10d:** migration `0091` sets the `lucide` row's `licence` to `ISC and MIT` (16 of 126 curated Lucide icons are Feather-derived, MIT); the shared registry, the generator and the `F3.32e` three-way gate change with it, and the gate now reads `0090` **and** `0091`. (4) **Decision 8:** `/attributions`, for every signed-in user, linked from the palette's licence line; lists the four global libraries — name, version, licence, source link, full notice from the bundle — through a data list that slice 2 (per-file credits) and slice 3 (organization libraries from the API) extend as **data, not page code**.

**Out (slices 2 and 3, or never).** `qet`/`wmpid`/`drawio` (0092); organization tables, `org.` keys, `mimic_library_settings`, the switch, SVG upload, `saxes`, the `mimic-symbol-libraries` API module (0093). **Palette hiding of retired symbols/libraries** — the bundle has no inactive set until decision 7's `GET /mimic-symbol-libraries` exists (ruling R1; the API is the enforcement in this slice). Any change to `0088`–`0090` (frozen), to the contracts in `packages/shared/src/contracts/`, to `openapi-registry.ts`, to `AGENTS.md` §6, to seeds, presets, `MimicScene` or the renderer. No new manifest dependency; the only `package.json` change is the root `typecheck:tests` list (§4). Retiring a global library or symbol stays a `bms_fleet` `UPDATE` until slice 3 — nothing in this slice flips an `active` flag outside a test's `finally`.
